# a52q gap analysis: 6.14 (obs/sm7125) vs mainline v7.3-rc5 (a52q/mainline) - 2026-10-01

Read-only analysis. Sources: git log/show on ~/src/linux-sm7125 obs/sm7125 (30 commits over the sm7125-mainline 6.14.7 base),
~/src/linux-a52q-mainline a52q/mainline (34 commits over 72d3fcf802c4), obs/a52q-mainline defconfig (51966e7),
~/linux-a52q/DEBUG.md, patchwork.kernel.org API (queried 2026-10-01). Nothing was booted or touched on the phone.
"Works" for 6.14 = DEBUG.md on-device verification. Mainline 7.3 has NEVER been observed booted to userspace
(2026-09-30 boot died to the U-Boot WDT; defconfig fix 51966e7 is untested). So every mainline "present" is build/dtbs_check-only.

Key structural fact: a52q/mainline = v7.3-rc5 + Erikas Bitovtas' 3 patches (compatibles, tzmem, initial DT) + our ports.
The 6.14 fork's sc7180.dtsi carries SoC nodes that do NOT exist in mainline sc7180.dtsi (verified by label diff):
camss, cci0/cci1 (+pinctrl), gpi_dma0/1, remoteproc_cdsp (+cdsp_mem), lpass_tlmm, rxmacro, txmacro, vamacro, swr1, swr2, sound.
Mainline camss.c has no sc7180 compatible at all (sm6150/sdm670/sm6350 only) and no sc7180-camss binding.

## a52q_defconfig (obs/a52q-mainline 51966e7) boot-critical audit
Already fixed: QCOM_WDT=y, OVERLAY_FS=y, REGULATOR_QCOM_REFGEN=y.
Still worth changing (none blocks reaching userspace; ranked):
- TYPEC_MUX_SM5714 unset + TYPEC_SM5714_CC=m: USB-C role/D+/D- path (CC may defer waiting for mux). Set both =y/m (prefer MUIC=y with CC) before OTG testing.
- DRM_PANEL_SAMSUNG_S6E3FC3=m (6.14 =y): DSI host defers until module loads; display stays on simple-fb. Acceptable; =y gives native display before userspace.
- QCOM_SMP2P_SLEEPSTATE missing (driver not ported) - needed for suspend with ADSP running.
- QCOM_Q6V5_PAS/MSS/ADSP, QCOM_IPA, ATH10K_SNOC, BT_QCA, QCOM_PD_MAPPER, SOUNDWIRE_QCOM, VIDEO_QCOM_CAMSS, I2C_QCOM_CCI, QCOM_SPMI_ADC5/TM5/TEMP_ALARM =m, same as 6.14; fine now that modules load, but the thermal ADC modules can leave thermal zones unreadable early. Not needed before userspace.
- Watchdog path: QCOM_WDT=y is the only WDT; U-Boot arms a 30 s WDT, so any boot that stalls >28 s before userspace pets it resets. Keep initrd/sysext merge fast.
- Not in defconfig at all (all camera/OIS/I2C_GPIO-based cam PMIC stuff): VIDEO_S5KGW1P/S5K3L6XX/IMX616/GC5035/A52Q_OIS_MCU, REGULATOR_S2MPB03=m present but no DT consumer.
